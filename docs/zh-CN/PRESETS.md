# 处方预设库清单（PRESETS）

本文件描述 `studio/src/data/presets.ts` 中全部预设数据的结构、清单与维护方式。
界面中的下拉框、搜索列表、"常用方案" 一键带入均直接读取该文件，**改数据只需改这一个文件**。

> 所有药品价格仅为演示排版数据，实际使用请按本单位药品目录自行修改。

## 1. 总览

| 导出名 | 含义 | 类型 | 数量 |
| --- | --- | --- | --- |
| HOSPITALS | 医院名称 | string[] | 40 |
| DEPARTMENTS | 科室名称 | string[] | 22 |
| DIAGNOSES | 诊断（按组） | DiagnosisGroup[] | 11 组 / 105 条 |
| DRUGS | 药品（含厂牌/规格/单价/用法） | DrugPreset[] | 77 |
| DOCTORS | 医师姓名 | string[] | 8 |

| GENDERS | 性别 | string[] | 2 |

## 2. 字段说明

### DrugPreset（DRUGS 的元素）

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| name | string | 药品通用名，**REGIMENS.drugs 必须与此完全一致** | 氢溴酸伏硫西汀片 |
| brand | string | 厂牌/商品名 | 石药 |
| spec | string | 规格，形如 "10mg x 14片/盒" | 10mg x 14片/盒 |
| price | number | 单价（元），保留两位小数 | 9.87 |
| usage | string | 默认用法用量，如 "每日1次 每次1片 口服" | 每日1次 每次1片 口服 |
| class | string | 药品分类，用于归类检索 | 抗抑郁药 |

### DiagnosisGroup（DIAGNOSES 的元素）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| group | string | 分组名，如 "心境障碍" |
| items | string[] | 该组下的诊断名称（ICD/中文精神科常用写法） |

### RegimenPreset（REGIMENS 的元素）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 方案名，显示为界面上的快捷按钮，**全局唯一** |
| diagnosis | string[] | 诊断列表，每项必须命中 DIAGNOSES 中的条目 |
| drugs | string[] | 药品名列表，每项必须命中 DRUGS 的 name（否则带不出规格与价格） |

## 11. 如何新增一条

### 新增药品

在 `DRUGS` 数组末尾追加一行（保持双引号、分号、2 空格缩进）：

```ts
{ name: "盐酸示例片", brand: "示例厂牌", spec: "5mg x 14片/盒", price: 12.34, usage: "每日1次 每次1片 口服", class: "抗抑郁药" },
```

要求：

1. `name` 为通用名且**不与现有药品重名**（重名会让 `makeDrug` 查到错误的价格）。
2. `spec`、`usage`、`brand`、`class` 均为非空字符串；`price` 为正数，保留两位小数。
3. 规格写法统一为 "剂量 x 装量/盒（或 /瓶、/支）"。

### 新增诊断

找到（或新建）一个分组对象，往 `items` 里加字符串；若新建分组，需保持 `{ group, items }` 结构：

```ts
{ group: "新分组名", items: ["诊断一", "诊断二"] },
```

### 新增常见方案（重要）

在 `REGIMENS` 追加：

```ts
{ name: "方案名", diagnosis: ["抑郁状态"], drugs: ["盐酸舍曲林片", "劳拉西泮片"] },
```

**约束（生成器按 name 查表，写错会静默带出空规格/0 元）**：

- `drugs` 里的每个字符串必须**逐字命中** `DRUGS[].name`；
- `diagnosis` 里的每个字符串必须逐字命中 `DIAGNOSES[].items`；
- `name` 全局唯一；`diagnosis` 与 `drugs` 均不得为空数组；
- 界面按 `MAX_DIAG_LINES`(8) 与 `MAX_DRUGS`(5) 截断，建议每方案诊断 ≤ 8、药品 ≤ 5。

### 新增医院 / 科室 / 用法 / 提示语

分别追加到 `HOSPITALS`、`DEPARTMENTS`、`USAGE_PRESETS`（字符串数组）、`TIP_PRESETS`（二维字符串数组，一组一条医嘱提示）。

## 12. 自检

改完预设后运行：

```bash
cd studio
node scripts/check-presets.mjs   # 预设一致性断言
npm run build                    # 类型/构建检查
```

断言脚本先用 Vite 自带的 rolldown 把 `presets.ts` 打包成 ESM 再动态导入（不新增任何依赖），覆盖：REGIMENS 的 drug 名与 diagnosis 是否命中库中、DRUGS/HOSPITALS/科室/诊断条目/方案名是否重复、
每条药品字段是否非空且价格有效，以及各项数量下限（医院 ≥30、科室 ≥20、诊断 ≥8 组且 ≥60 条、药品 ≥45、方案 ≥15、用法 ≥20、提示语 ≥6 组）。
